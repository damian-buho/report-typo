# Report Typo

Бібліотека для браузера, з якою читачі повідомляють про одруківку, виділивши її й натиснувши Ctrl+Enter (Cmd+Enter на macOS). Звіт разом із текстом довкола виділення надходить до report-relay, на вебхук або до вашої власної функції.

## Що надає цей проєкт

- **Пакунок npm** `report-typo`

## Встановлення

Додайте пакунок до свого проєкту:

```sh
npm install report-typo
```

## Збирання

Клонуйте репозиторій і виконайте `make` — кожен крок збирання, ціль і точка входу описані в [Збирання](BUILD.md).
